Strict use of semantic containers (<header>, <nav>, <main>, <section>, <article>, <footer>) allowing screen reader users to jump between landmarks seamlessly.

Custom high-contrast focus rings (3px offset outline) applied to all interactive links, buttons, and form inputs when navigated using Tab key.

Dynamic single-page view transitions and form state updates announce state changes automatically using an invisible aria-live="polite" region.

Project detail modals lock focus strictly inside the dialog while open and close reliably when the Escape key is pressed.

Form controls are explicitly linked to labels via for and id. Dynamic errors are linked via aria-describedby and flagged with aria-invalid="true".
